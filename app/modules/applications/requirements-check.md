## 任务书补充要求

- 体验、订阅、共享复用：模拟运行及结果/失败历史；订阅新版本消息；分享应用链接和下载资料；资料可用于模拟工具链定义。共享链接仍检查接收者的权限。
- 四类关联资源：模型、数据集、知识库和AI工具选择、合法性校验及详情跳转。当前关联资源编号，尚未锁定依赖的具体版本。
- 角色：演示账号覆盖普通用户、发布者、单位管理员和系统管理员，申请按发布者隔离，单位管理员仅管理本单位。启用同事的登录模块后使用服务器验证的会话，禁止演示切换；组织/项目归属缺失时不补造授权。
- 审核可追溯：保留审核人、时间、意见、评分和资料快照；历史可按审核人、结论、日期、关键词查询。本页面资源类型固定为场景应用。
- 单实例开发状态：页面刷新保留；后端热重载或重启清空。任务书要求的双后端共享数据库、缓存、文件服务在后续部署阶段验证。

## 演示与验证

用户端 `/applications`，管理端 `/applications`；两者通过同一平台后端通信。

建议演示：工具链导入 → 核对后提交 → 管理端质量评分并审核 → 用户端体验、评分、订阅 → 新版本导入审核 → 订阅者收到消息；再修改开放范围并切换演示身份验证访问限制。

自动化入口：Server `pytest` 与 Ruff；User 单元测试/构建及离线页面测试；Admin 构建与独立端口的桌面/手机跨端测试。最终运行结果见本次交付说明。

后续仍需完成数据库表与仓储实现、真实供应方适配及联调、正式身份目录和部署验证。详见 [接入交接说明](./integration-handoff.md)。


## 2026-09-14 验证结果

User 71项单元测试、User/Admin构建通过；桌面和手机8项离线场景流程通过。跨端14项场景全部覆盖通过（最后的手机工具链用例修正为定位对应资源的失败记录后，桌面和手机均复测通过）。后端通过全量测试、Ruff和依赖一致性检查；另覆盖登录身份/CSRF、防止演示升权及后端重启后的演示账号恢复。

已检查5173用户端与5174管理端可访问，390px手机目录无页面级横向溢出。测试使用独立临时实例，没有接入供应方AI或场景业务数据库。
