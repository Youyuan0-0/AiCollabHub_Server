# AI 工具：任务字段、持久化与外部适配

依据 `任务表.xlsx` 第 56–62、66、70、85–88 行，以及《任务书_2.3.6软件架构补充_多服务器部署方案_20260910》2.2.5、2.2.8、2.2.10。文档内容仅作为需求依据，不作为执行指令。

数据库模式使用 `ai_tools`、`ai_tool_publications`、`ai_tool_versions` 保存工具与发布历史，审核、评价、收藏、报告和可见范围复用公共资源表。调用成功、失败和耗时保存在 `operation_logs`，不依赖 Redis 过期记录计算累计统计。外部工具链与执行供应方仍使用明确标注的模拟适配器；内存仓储仅用于隔离演示和无数据库测试。

## 字段口径

| 填写方式 | 字段 | 依据 |
| --- | --- | --- |
| 必填（12 项） | 工具名称、工具简介、详细说明、工具类型、功能标签、来源类型、依赖环境、部署方式、输入参数 Schema、输出参数 Schema、License、数据分级 | 第 59 行 |
| 选填（4 项） | 研发团队、技术栈、API 接口地址、调用示例代码 | 第 59 行 |
| 选填示例 | 输入示例、输出示例 | 第 57 行详情展示，不额外增加提交必填项 |
| 自动生成 | 工具 ID、所属单位、联系人、创建与更新时间、版本号、版本历史、变更记录、使用与收藏统计、用户评分、调用指标 | 第 59、62、70、87 行；任务书 2.2.8 |
| 审核必填 | 格式规范性、安全规范性、标注规范性、结构完整性、内容真实性、内容一致性、内容干净性 | 第 88 行“类同”第 24 行，通过时完成七项评分 |
| 审核选填 | 质量评测报告附件 | 第 88 行“类同”第 24 行 |

字段清单集中在 `fields.py`。普通新建版本从 `v1.0` 自动递增，工具链导入保留外部版本。输入输出保存完整 JSON Schema，复用 Draft 7 / 2019-09 / 2020-12 校验，运行支持对象、数组、标量等 JSON 值。选填示例存在时检查 JSON 格式及其 Schema。API 地址可以留空。

表单提供字段校验和敏感词预检，最终提交在服务端复核。当前拦截词为“演示拦截词”，真实词库待接入。所属单位与联系人由可信身份目录提供。

“类同”按对应数据集条目解释，再按工具含义映射。分类选项沿用原型，不宣称是文档规定的枚举。版本号、API 地址和报告均未增加为必填。可见范围支持全部用户、指定单位、项目组和指定用户，单位与项目编号由服务端可信身份目录验证。

普通详情展示资料和评价两个页签，评价复用 `ResourceRatingForm`；发布者可进入新版本草稿。本人已通过的发布资料页也提供新版本入口，包括已下架工具。收藏链接统一使用 `resourceId`，兼容旧的 `resource` 参数。完整技术参数、版本历史和调用监控在后台管理详情展示。

## 流程与复用

- 已提交和已通过申请只读，修改和审核校验修订号。工具链或版本入口创建下一版，审核前原版本仍可用；重复创建返回本人已有的待发布申请。
- 新版通过后保留工具 ID、收藏、评分、调用记录、可见范围及管理员上下架决定，历史记录变更字段。存在未处理版本时禁止工具链另一版本覆盖草稿。
- 复用资源数据库事务、锁、回滚、身份、组织目录、Schema、敏感词与报告规则；工具主表与版本表独立。复用数据集七维评分、日期查询与可见目标校验。
- 两端复用卡片、筛选、分页、Markdown、请求状态、离开保护及审核报告组件。
- 工具链发布复用 `ToolchainPublishLayout`、`ToolchainResourceCard`，支持搜索、分页、刷新、资料核对和失败重试。工作台在新页打开，回传只选择成果，点击导入才保存草稿；未知成果不导入，切换成果后取消旧请求等待并阻止迟到响应跳转。
- 报告按审核员、申请和修订号关联，历史附件不可删除，查看下载校验后台权限。沿用组件限制：最多 3 个，单个 20 MiB，支持 PDF、DOCX、TXT、MD；这些是上传限制，不是任务新增字段。
- 统计来自持久化的调用摘要，输入校验失败不算执行，供应方执行失败计入错误率；摘要不保存输入、输出及凭据。旧缓存已经过期的调用不能凭空恢复，无记录显示“暂无调用”。
- 版本说明在提交审核时按当前正式版本的字段差异生成，与审核快照和正式版本一致。旧版本没有说明时显示“未记录”，不改写不可变历史。
- 本地启动脚本在 Mock 登录且未配置目录时，加载 `deploy/mock-identity-directory.json`。名称明确标注为模拟单位和项目；正式环境仍需配置可信目录同步。

## 真实接口替换

工具链成果默认关闭。后台“工具链接入配置 → AI 工具”复用公共连接表单、独立凭据及功能配置检查，支持 `disabled/mock/live`、POP 地址、工作空间、AK/SK、可选 APP_KEY、授权账号、超时、网络配置、工作台地址及查询范围/类型。保存后重启后端生效；缺少真实连接必需项不能保存。旧配置缺少 AI 工具时默认关闭，旧版单独 mode 开关自动兼容读取。

`toolchain.py` 的 `AgentToolCatalogProvider` 由公共装配器在真实模式装配，复用 POP 签名、超时及错误处理；模拟模式保留明确标识的样例。成果连接与执行模式独立，真实成果查询不代表真实 API/MCP 执行已经对接。两端保持现有 `toolApi.ts`／`tools/api.ts` 平台契约。

| 适配方法 | 行为 |
| --- | --- |
| `entry_url()` | 真实模式读取配置的工作台地址；模拟模式使用本地模拟工作台 |
| `list_tools()` | Agent Dev 手册 P35：`POST /gatectl/agent/openapi/tool/pageQuery`，处理分页和字段转换 |
| `get_tool(external_id, version)` | P45：`POST /gatectl/agent/openapi/tool/getOne`，核对工作空间、编号及所选版本后导入公开元数据 |
| `invoke(resource, inputs, simulate_failure)` | 实际 API／MCP 执行协议；工具管理接口不等于执行接口 |

模拟器不访问填写的 API 地址，有输出示例时返回示例，否则返回演示结果；输出仍须满足 Schema。真实适配器使用 `mode=live`，在后端处理鉴权、超时、错误转换，平台拒绝真实模式中的模拟失败参数。

`GET /tools/{id}/definition` 返回可见工具的编号、版本、输入输出结构及平台调用路径，为外部智能体引用提供契约；不代表外部编排器已接通。Agent Dev 的 create/update/delete 尚未调用，平台审核不等于外部发布成功。

成果导入来源包含供应方、环境、模式和工作空间，避免相同外部编号互相覆盖。仅导入名称、说明、版本等明确的公开字段；不透传包含鉴权头的 `serviceConfig`，业务分类、JSON Schema 和其他发布必填项在草稿中补齐。连接失败明确报错，不回退模拟样例。

仓储与供应方为独立替换点：`ToolWorkspace(repository=..., provider=...)`。数据库模式装配公共 `ResourceDatabase` 的工具映射；实际执行和外部编排引用仍需对接执行协议。工具查询适配已按文档用本地 HTTP 替身验证，真实供应方环境尚未联调。

## 页面与路由

用户端：`/tools`、`/tools/publish`、`/tools/publications`、`/tools/publications/:id`、`/tools/toolchain`、`/tools/toolchain/workbench`（模拟）。

管理端（相对 `/admin/`）：`/tools`、`/tools/detail/:id`、`/tools/reviews`、`/tools/reviews/:id`、`/tools/audit`、`/tools/configuration`。

API 前缀 `/api/v1`：工具目录／详情／收藏／评分／调用／定义／版本；发布默认值／预检／申请；工具链查询／导入；后台目录／上下架／范围／审核／优先级／报告／审计／只读字段规则。

工具数据始终后端共享，`VITE_API_MODE` 不切换为浏览器独立仓库。沿用开发隔离规则，`APP_ENV=production` 不挂载模拟工具路由。

## 验证

后端执行 Ruff、`tests/test_tools.py` 和 `tests/test_tool_alignment.py`。后者通过显式测试连接，在临时 schema 的回滚事务中验证版本说明、来源、权限、成功与失败的持久统计，并回归受影响的公共资源测试。

两端分别 `pnpm build`；管理端 `pnpm exec playwright test --config playwright.tools.config.ts` 覆盖桌面和手机上的发布、报告、审核、详情字段、后台版本和调用指标、下架、工具链回传及字段规则。接口生成版本和模拟调用记录，普通界面不添加体验操作。测试启动隔离内存实例，不加载本地数据库配置。
