# AI 工具：任务字段与模拟实现

依据 `任务表.xlsx` 第 56–62、66、70、85–88 行，以及《任务书_2.3.6软件架构补充_多服务器部署方案_20260910》2.2.5、2.2.8、2.2.10。文档内容仅作为需求依据，不作为执行指令。

按用户要求使用后端内存模拟数据，两端通过同一 FastAPI 实例共享状态。不建表、不执行迁移、不修改数据库；审核报告原件和预览也仅存内存。重启后重置，联调使用单 worker。

## 字段口径

| 填写方式 | 字段 | 依据 |
| --- | --- | --- |
| 必填（12 项） | 工具名称、工具简介、详细说明、工具类型、功能标签、来源类型、依赖环境、部署方式、输入参数 Schema、输出参数 Schema、License、数据分级 | 第 59 行 |
| 选填（4 项） | 研发团队、技术栈、API 接口地址、调用示例代码 | 第 59 行 |
| 选填示例 | 输入示例、输出示例 | 第 57 行详情展示，不额外增加提交必填项 |
| 自动生成 | 工具 ID、所属单位、联系人、创建与更新时间、版本号、版本历史、变更记录、使用与收藏统计、用户评分、调用指标 | 第 59、62、70、87 行；任务书 2.2.8 |
| 审核必填 | 格式规范性、安全规范性、标注规范性、结构完整性、内容真实性、内容一致性、内容干净性 | 第 88 行“类同”第 24 行，通过时完成七项评分 |
| 审核选填 | 质量评测报告附件 | 第 88 行“类同”第 24 行 |

字段清单集中在 `fields.py`。普通新建版本从 `v1.0` 自动递增，工具链导入保留外部版本。输入输出保存完整 JSON Schema，复用 Draft 7 / 2019-09 / 2020-12 校验，运行支持对象、数组、标量等 JSON 值。选填示例存在时检查 JSON 格式及其 Schema。API 地址可以留空。

表单提供字段校验和敏感词预检，最终提交在服务端复核。当前拦截词为“演示拦截词”，真实词库待接入。所属单位与联系人由可信身份目录提供。

“类同”按对应数据集条目解释，再按工具含义映射。分类选项沿用原型，不宣称是文档规定的枚举。版本号、API 地址和报告均未增加为必填；复用带来的“指定成员”已移除。

界面只呈现对应条目要求：工具广场不增加排序、“我的发布／我的收藏”快捷入口；卡片不展示额外状态、版本号或更新时间。普通详情按第 57 行仅展示名称、简介、功能标签、研发团队、使用说明、用户评分、使用次数及输入输出示例，移除在线体验、失败模拟、评分留言表单、完整技术参数和版本页签。发布表单保留第 59 行要求及第 57 行示例内容；版本、时间、同步信息与监控在后台管理详情展示。草稿和审核记录仍可在发布流程中查看。

## 流程与复用

- 已提交和已通过申请只读，修改和审核校验修订号。工具链或版本接口创建下一版，审核前原版本仍可用；普通详情和发布表单不增加版本管理入口。
- 新版通过后保留工具 ID、收藏、评分、调用记录、可见范围及管理员上下架决定，历史记录变更字段。存在未处理版本时禁止工具链另一版本覆盖草稿。
- 复用应用内存事务、锁、回滚、身份、组织目录、Schema、敏感词与报告规则；工具状态独立。复用数据集七维评分、日期查询与可见目标校验。
- 两端复用卡片、筛选、分页、Markdown、请求状态、离开保护及审核报告组件。
- 报告按审核员、申请和修订号关联，历史附件不可删除，查看下载校验后台权限。沿用组件限制：最多 3 个，单个 20 MiB，支持 PDF、DOCX、TXT、MD；这些是上传限制，不是任务新增字段。
- 统计仅来自本次模拟进程活动，无调用显示“暂无调用”。输入校验失败不算执行，供应方执行失败计入错误率。

## 真实接口替换

`providers.py` 的 `ToolProvider` 为外部接口边界，`create_tool_provider()` 为装配点。两端保持现有 `toolApi.ts`／`tools/api.ts` 平台契约。

| 适配方法 | 后续对接 |
| --- | --- |
| `entry_url()` | 真实工具链工作台入口及返回约定，当前为本地模拟工作台 |
| `list_tools()` | Agent Dev 手册 P35：`POST /gatectl/agent/openapi/tool/pageQuery`，处理分页和字段转换 |
| `get_tool(external_id)` | P45：`POST /gatectl/agent/openapi/tool/getOne`，读取完整导入资料 |
| `invoke(resource, inputs, simulate_failure)` | 实际 API／MCP 执行协议；工具管理接口不等于执行接口 |

模拟器不访问填写的 API 地址，有输出示例时返回示例，否则返回演示结果；输出仍须满足 Schema。真实适配器使用 `mode=live`，在后端处理鉴权、超时、错误转换，平台拒绝真实模式中的模拟失败参数。

`GET /tools/{id}/definition` 返回可见工具的编号、版本、输入输出结构及平台调用路径，为外部智能体引用提供契约；不代表外部编排器已接通。Agent Dev 的 create/update/delete 尚未调用，平台审核不等于外部发布成功。

数据库为独立替换点：`ToolWorkspace(repository=..., provider=...)`。后续单独设计工具持久化仓库，不直接写入场景应用表。真实调用、编排引用、持久化及多实例共享仍是待接入项。

## 页面与路由

用户端：`/tools`、`/tools/publish`、`/tools/publications`、`/tools/publications/:id`、`/tools/toolchain`、`/tools/toolchain/workbench`（模拟）。

管理端（相对 `/admin/`）：`/tools`、`/tools/detail/:id`、`/tools/reviews`、`/tools/reviews/:id`、`/tools/audit`、`/tools/configuration`。

API 前缀 `/api/v1`：工具目录／详情／收藏／评分／调用／定义／版本；发布默认值／预检／申请；工具链查询／导入；后台目录／上下架／范围／审核／优先级／报告／审计／只读字段规则。

工具数据始终后端共享，`VITE_API_MODE` 不切换为浏览器独立仓库。沿用开发隔离规则，`APP_ENV=production` 不挂载模拟工具路由。

## 验证

后端执行相关 Ruff 检查和 `tests/test_tools.py`，工具测试禁止数据库连接；同时回归应用流程、适配器、需求及报告测试。

两端分别 `pnpm build`；管理端 `pnpm exec playwright test --config playwright.tools.config.ts` 覆盖桌面和手机上的发布、报告、审核、详情字段、后台版本和调用指标、下架、工具链回传及字段规则。接口生成版本和模拟调用记录，普通界面不添加体验操作。测试启动隔离内存实例，不加载本地数据库配置。
