# 第一阶段任务清单

阶段主题：将 HTML 原型转换为 Vue 组件化项目，搭建前后端服务框架及微服务体系。

更新日期：2026-09-07。执行背景：目前由一名开发人员负责；后端选用 FastAPI + SQLAlchemy；外部接口、生产数据库及具体信创环境尚未确定。

本清单用于拆解第一阶段交付，不表示第一阶段整体已经完成。状态中的“已完成”仅针对该行限定的本地工作；Mock 流程、接口草案和自动化测试不等于真实系统已接通或通过信创验收。

## 一 范围与依据

依据为项目任务书、HTML 网页原型、用户提供的聊天截图及本次明确的分工。我们负责平台入口集成、用户端、管理端和平台后端，不自行开发问答算法、RAG 引擎、模型训推、数据集加工或 AI 工具本身。

第一阶段形成可以继续开发和联调的工程基础，打通约定的 Mock 示例链路。真实 SSO、供应方接口、完整权限模型、业务持久化及目标环境适配按清单另行实施。数据集、模型、智能体和工具的供应方凭证只能保存在后端。

| 平台 API | 用户及管理端业务入口、身份权限、资源目录、申请反馈和平台数据 | 独立进程、配置、健康检查及版本化 API |

## 八 推荐执行顺序与验收门槛

1. 先确认 U/A/B/M 的职责与接口草案，尤其是管理端范围和“微服务体系”的最小验收口径。
2. 建立独立管理端工程，保留用户端发布入口；落地统一登录状态、菜单与权限控制。
3. 确认数据库后，实现资源目录与“发布、审核、查询状态”最小持久化闭环；每条业务接口落实权限依赖。
4. 建立集成服务及 Mock 供应方，完成跨服务调用、超时失败和身份校验示例。
5. 完成容器化、入口代理、日志、虚拟机部署和离线依赖准备。
6. 运行阶段测试，整理演示证据；在目标浏览器和信创环境中逐项补充验证。

阶段整体完成至少应满足：两端工程可独立启动及构建；平台后端可独立运行；约定的最小多服务链路实际可运行；鉴权、分页、错误及取消契约有测试；配置与部署步骤可复现；未接通的外部能力明确标识，不以模拟成功冒充真实集成。
